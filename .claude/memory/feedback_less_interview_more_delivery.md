Don't ask multiple clarifying questions before acting. Read the code, form a plan, state it briefly, then execute.

**Why:** User finds excessive back-and-forth frustrating and slow. Code context usually answers questions better than asking.
**How to apply:** For complex tasks, state the plan in 2-3 lines then implement. Ask only if genuinely blocked on something that can't be inferred.
