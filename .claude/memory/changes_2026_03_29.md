## Changes Made 2026-03-29

### PWS No Longer Trades Autonomously
- PWS signals from Ruth are now data-only — buffered and fed to Jonah
- Wendy no longer executes anticipation BUY trades from PWS data
- All trade entries now come from METAR threshold detection or Jonah /trigger

### Spread Guard Removed
- Previously skipped trades when spread > 6c
- No longer needed — removed from trading guards

### Price Floor 5c
- Was: gamma < 10% (20c floor)
- Now: gamma < 5% (5c floor)
- Ceiling unchanged at 75%

### FOK → GTC Fallback
- When FOK (Fill-or-Kill) order is not immediately matched, system falls back to GTC (Good-Til-Cancelled)
- 5s verify window (5 attempts × 1s)
- FOK verify attempts increased from 3 to 5

### Max 1 Bucket Jump on Jonah Trigger
- Jonah can only trigger 1 bucket above current METAR (4°F for F stations, 2°C for C stations)
- Prevents speculative far-out bets on temperature jumps

### Jonah Exit Logic (SELL when confidence < 20%)
- Jonah tracks triggered BUYs per station in `_last_triggers` dict (proxy.py)
- If a previously triggered bucket's range_prob drops below SELL_THRESHOLD = 0.20, Jonah fires a SELL trigger to Wendy
- Allows exiting positions when confidence collapses

### METAR and Jonah Trade Independently
- METAR buys confirmed threshold crossings, Jonah buys predictions
- Multiple positions per station are valid
- No conflict between the two signal paths

### Downward ROTATE Blocked
- Jonah trigger supports BUY and upward ROTATE only
- Downward ROTATE (moving to a lower temperature bucket) is blocked
- Daily max temperature is monotonic (never descends)

### Timing Thresholds Updated
- WAIT: <30% (was <60%)
- SMALL: 30-40% (was 60-70%)
- MEDIUM: 40-55% (was 70-80%)
- STRONG: 55%+ (was 80%+)

### Ensemble Floor Filter
- Temperatures below the observed daily max are removed from probability distributions before range detection
- Prevents ensemble from predicting below what has already been observed

### Chronos Thread-Safe Lock
- Chronos inference uses a threading lock to prevent concurrent model access
- Ensures safe parallel station processing

### GPT-5 Temperature Param Fix
- GPT-5 requires `max_completion_tokens=16384` because it uses internal reasoning tokens
- Uses `response_format=json_object` with system message (required by API)

### RAG 5yr Backfill
- Qdrant populated with 18,250 points covering 5 years of historical data
- 10 US stations, auto-backfill from Wendy DB if collection is empty

### LightGBM 10 Stations
- 7 quantile models trained on 18,238 samples
- Covers all 10 US stations with 5yr NOAA/IEM data

### International Stations Removed
- EGLC (London), LFPG (Paris), CYYZ (Toronto) removed
- System now covers 10 US-only stations (all °F)

### Legacy Qdrant Collection Cleanup
- Old/unused Qdrant collections cleaned up
- Single collection for current 10-station RAG

### Trigger Cooldown Removed
- Jonah /trigger no longer has a cooldown period between fires
- Allows faster response to changing market conditions
