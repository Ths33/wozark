Wozark Architecture

Ruth — Sensor

  • • Synoptic primary, TGFTP fallback + parallel :51/:53
  • • 14 polls/hour + hot-poll :50-:58 @ 3s (T-group)
  • • METAR → Wendy (circuit breaker) + Jonah (fire-and-forget)

Wendy — Trading Brain

  • • Signal → runningMaxC → bucket → 8 guards → BUY/ROTATE

  • • 150-400ms hot path (book cache 30s, payload cache 30min)
  • • Monitor 3min: auto-sell @ 99¢, duplicate cleanup, sell retry
  • • WS broadcasts 9 event types to Marty

Jonah — Learning Analyst

  • • LEARNING ONLY — TRIGGER_ENABLED=False (proxy.py:26)
  • • 4-source ensemble: LightGBM·Chronos·Open-Meteo·RAG

  • • Nightly learning: resolve → Qdrant + DB (10 UTC)
  • • Reads Wendy DB for actual max temps (cross-DB)

Marty — Dashboard

  • • 7 pages: home, station, logs, decisions, jonah, settings, login
  • • Everforest dark theme, Manrope font, BRT timezone
